# tachyurgy/homebrew-tap

Homebrew tap for [hey-claude](https://github.com/tachyurgy/hey-claude) — say
"Hey Claude" to dispatch a Claude Code background agent (on-device voice wake word).

```bash
brew install tachyurgy/tap/hey-claude
```

> Note: this tap and the formula's release tarball must be public, and the
> formula's `sha256` must point at a tagged release. See
> [RELEASE.md](https://github.com/tachyurgy/hey-claude/blob/main/RELEASE.md).
